## Assumptions

- 重複判定は「同一 Room かつ同一 Date で、[Start, End) の区間が共通部分を持つ」こととした。終了時刻と開始時刻が一致する（例: 10:30 終了 → 11:00 開始）ケースは接するのみで区間が共通部分を持たないため、重複とはみなさなかった。
- フィクスチャの全49行（ヘッダ・区切り行除く44件の予約データ行）をすべて Room+Date でグルーピングした上で総当たり比較を行った。抜け漏れの有無は未検証（自動テストは実行していない、手動での目視突合のみ）。
