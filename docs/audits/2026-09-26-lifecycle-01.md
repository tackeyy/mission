# Lifecycle-01 テスト価値監査

## 対象と結論

- 関連Issue: [全体 #805](https://github.com/tackeyy/mission/issues/805)、[責務 #813](https://github.com/tackeyy/mission/issues/813)、[監査 #828](https://github.com/tackeyy/mission/issues/828)。
- 対象ソース: [`f0baddfb753c53aa9a51a3781076b6d1e61d8aad`](https://github.com/tackeyy/mission/tree/f0baddfb753c53aa9a51a3781076b6d1e61d8aad)。本監査は lifecycle-01 台帳の137テスト宣言を対象にした。
- 実行基準: 同コミットで最初に取得した full 実測だけを使用した。全スイート、外部サービス、有料提供者、live benchmark は再実行していない。
- 結論: 134宣言は **R（維持）**。`test_resume_gap_keeps_a_reason_and_rollup_conserves_elapsed` は、resume後の経過時間rollup保存を検証していないため **F（要修正）** とした。対応は [#872（resume gapのrollup保存を検証するassertionを追加する）](https://github.com/tackeyy/mission/issues/872)。`test_next_evidence_submitted_for_checker_reports_terminal` は、`test_next_evidence_submitted_role_matrix` へ ("checker", "report-terminal") を1行加えれば同一故障を検出できるため **C（統合候補）** とした。`test_c2_direct_write_allowlist_is_empty` は、同一の空集合assertを含む広いinventoryテストが保持されることを条件に **D（削除候補）** とした。対応は [#862（C2許可リストの空集合検査を既存inventoryへ集約）](https://github.com/tackeyy/mission/issues/862)。

## 件数と観測限界

- 台帳: 137宣言、重複ID 0。初回 full 実測では185 collected、185 passed、0 skipped、JUnit testcase時間合計46.976秒。
- collected は parameterize 展開後のケース数であり、宣言数とは異なる。passed/ skipped はその初回実行結果で、現在の再実行結果ではない。
- JUnit時間はケース別のsetup/teardown込みの合計であり、並列実行のwall時間、削減後時間、flake率、保守時間はいずれも未計測である。
- 137件すべてで、固定ソースの同名FunctionDef（decoratorを除く `ast.get_source_segment`）のUTF-8 SHA-256が台帳の `source_sha256` と一致した。locatorもAST上の関数名・開始/終了行と一致した。これらは対応確認であり、維持判断の証明には使用していない。
- 各行は実テスト本文、parameter入力（該当4宣言）、直接owner、consumerを1 hop、最も近い実在テストを照合した記録である。テスト名や隣接関数名だけから契約を推定していない。

## 判定記号

- **R**: 単一の現実的故障を検出するため維持する。**F**: 契約を維持したままassertion、fixture、または検証境界を修正する候補。**C**: 同一故障を同一境界で検出する他テストへ統合する候補。**D**: 契約が不要、または保持する防御で同じ故障を検出できるため削除する候補。**U**: 根拠不足。
- closestは単なる機械的な隣接選択ではなく、入力境界、状態、観測結果、失敗時の副作用が最も近い実テストを記録した。

## 共通ownerと実行経路

- activity: `skills/mission/lib/activity_segments.py` の `transition_activity_phase` / `summarize_activity_states`、および `skills/mission/bin/mission-state.py` のCLI遷移経路。
- next/cleanup/agent/preflight: `skills/mission/bin/mission-state.py` の `cmd_next` / `cmd_cleanup_stale`、状態読取、PID検査、CLI出力・終了コード。
- archive/snapshot: `skills/mission/lib/worktree_archive.py` の `validate_worktree_archive_bundle` / `read_validated_archive_authoritative_snapshot` とpointer publish・改ざん検知経路。
- calibration: `skills/mission/lib/` 配下のaudit/benchmark集計、measurement文書の型検証、runner summary。
- command inventory: `skills/mission/bin/mission-state.py` のparser/thin adapter、`skills/mission/lib/mission_application/lifecycle.py`、禁止書込み解析の境界。
